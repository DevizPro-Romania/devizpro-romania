Cont DevizPro

Neconectat

Înregistrează-te cu e-mail și parolă. Autentificarea și sincronizarea online se activează după configurarea Firebase și publicarea aplicației pe un domeniu HTTPS autorizat.

Conturile online nu sunt încă active. Completează configurația Firebase, activează Email/Password, configurează Firestore și deschide aplicația de pe HTTPS.

Configurare Firebase

Configurația se obține din Firebase Console → Project settings → Your apps → Web app. Cheile web Firebase sunt identificatori publici; securitatea datelor trebuie impusă prin regulile Firestore.

Configurarea rămâne în acest browser. Nu introduce parole Firebase sau chei private aici. Activează Email/Password în Authentication și creează Firestore Database în Firebase Console.

Pașii pentru activare

  1. Creează un proiect la console.firebase.google.com.
  2. Adaugă o aplicație Web și copiază valorile de configurare de mai sus.
  3. În Authentication → Sign-in method activează Email/Password.
  4. Creează Firestore Database și aplică reguli care permit fiecărui utilizator să citească/scrie numai documentul cu propriul UID.
  5. Salvează configurația și apasă „Conectează Firebase”.
